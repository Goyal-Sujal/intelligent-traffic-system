# Intelligent Traffic Congestion Monitoring System

## Description
This project predicts traffic congestion using Machine Learning and adjusts traffic signals dynamically.

## Features
- Traffic level prediction (Low, Medium, High)
- Adaptive signal control
- Uses Random Forest algorithm

## Technologies Used
- Python
- Scikit-learn
- NumPy
- Pandas

## How to Run
1. Install dependencies:
   pip install numpy pandas scikit-learn
2. Run the code:
   python traffic_model.py
